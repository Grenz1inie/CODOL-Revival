# 本地实验与续接材料

此目录保留已执行实验的源码、范围说明和工作记录，供恢复分析使用，不属于管理器
生产入口。脚本可能绑定当时的本机路径、进程身份或分析快照；恢复前先读对应范围
说明并核对哈希，不批量运行。尤其`repair-instance-access.ps1`是历史实例权限修复
脚本，归档不代表再次执行的授权。

生成的EXE、游戏资源、反编译输出、分析数据库、REA快照、抓包、玩家数据和日志
保留本地并由本目录`.gitignore`排除。正式测试所需的可分发合成fixture位于版本
测试目录，另有来源说明。Git提交不会备份这些本地证据文件；勿清理work或runtime。
