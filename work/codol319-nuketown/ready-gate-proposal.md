# 3.19 真人 Ready 门控提案

49ea5c7 的实机验收失败：用户报告进房仍倒计时。PID76284 的只读快照显示
18名成员 ready 都为0，房间自动模式仍为1；加载器日志包含 `+set 3291 0`。
因此启动参数不能保证本地等待厅使用普通 Ready 分支。

本提案的代码：`ready_gate_proposal.py`。它只生成补丁字节并在 Unicorn
虚拟内存中测试，不打开游戏进程，不写 EXE，不会启用任何实机补丁。

## 已准备的修改

- 目标：3.19 `0x63c5e0` 自动匹配开局入口，原始6字节 `55 8b ec 83 ec 08`。
- 仅针对原赛单110的本版原生索引25，且本地房主UID1000001仍在首个成员槽位。
- 自动匹配阶段1/2且真人 ready=0时直接返回。真人Ready后执行原始函数；
  已经进入倒计时的阶段继续原始流程。其他赛单、身份与空房间也保持原始流程。
- 保存/恢复寄存器和标志，重放被替换的完整原生指令；只对静态VA按模块基址重定位，
  不二次重定位运行时房间指针。
- 若获准实机实验，目标仅限管理器的3.19隔离实例，先备份档案；原游戏文件不改。
  退出进程后内存修改消失。生产接入尚未编写，也未获本次进程写入授权。
