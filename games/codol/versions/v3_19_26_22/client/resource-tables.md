# 3.19 本机资源提取

输入仅限身份已核验的3.19客户端加载资源；调用方提供只读内存接口。`resource_tables.py`读取物品索引、武器配件和商城定义，`loaded_resources.py`读取DB命名资产、配装字段偏移及当前地图碰撞。两者不读取玩家库存或钱包。

布局依据3.19原生消费者及旧工具反汇编：物品分段索引`0x779584c`、定义表`0x779583c`、配件表`0x1978640`，SKU索引`0x7798008`、定义`0x7798000`、产品`0x7797fe8`；SKU字段按地址和本次进程密钥解码，不能复用上次进程指针。DB查找`0x49c870/0x49ca70`；公开DDL的版本233、校验1248641861，60套配装从实际偏移表生成。clipMap位于`0x77e1c00`，先核对完整地图名再读取有界几何数组。

定向测试先失败后实现，覆盖普通/运行时SKU、旋转编码、物品别名、非武器项、缺表/坏尺寸/读取失败、DB环链、DDL身份、地图身份、梯子和截断读取。

2026-10-17只读提取已运行客户端PID 47740：15,698条配件和41,885条价格与旧参考完全一致；40,635条物品映射中的67xxx段已有1,000条与旧包不同，必须使用当前资源映射，不固定旧包结果。武器注册顺序（含none共1,136项）、60套配装偏移及loadoutVersion与参考一致。

从既有Seatown捕获的内存记录重新提取最小碰撞数据：102,556,296字节减为3,157,222字节。3个梯子定义相同；源码碰撞工具加载14,965个brush和77,343个三角形，140次确定性轨迹与旧工具/旧捕获组合无差异。此验证证明提取布局和消费者兼容；尚需在首次准备流程接入，并用原游戏首次加载地图生成，不能把旧捕获当作交付输入。
