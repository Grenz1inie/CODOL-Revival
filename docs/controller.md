# 本地 Web 控制器

## 启动与使用

在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Start.ps1`。入口先检查环境并启动 Web 控制器；游戏启动流程确认认证/大厅/STUN及Rust对局服务就绪后请求管理员身份启动游戏，最后打开 <http://127.0.0.1:8765/>。也可右键根目录的 `Start.ps1`，选择“使用 PowerShell 运行”；正常使用需要保留并确认游戏 UAC 提示。

| 参数 | 用途 |
|---|---|
| `-CheckOnly` | 只读检查，失败返回非零退出码，不启动服务、浏览器或游戏 |
| `-NoGame` | 只启动网页控制器，游戏及模拟服务器可随后从网页一起启动 |
| `-NoBrowser` | 不自动打开浏览器，可与 `-NoGame` 合用 |
| `-PythonPath 'C:\路径\python.exe'` | 指定 Python；默认优先项目 `.venv`，其次 PATH 中首个 Python |
| `-StartupTimeoutSeconds 20` | 每项服务的启动等待时间，默认 20 秒 |

预检查覆盖 Python 3.9+（本机验证为 3.13）、`requirements.txt` 中的锁定依赖、游戏 EXE 和本地地址配置、证书有效期/签名/私钥、游戏 CA 信任、控制器设置与前端产物。端口检查覆盖 TCP 443、TCP/UDP 3074 和 TCP 8765，并核对所属进程；其他程序占用时显示 PID 并停止本次启动。缺依赖时会给出补齐命令，不自动安装或更改游戏/系统配置。

首次构建：在 `web/` 运行 `npm ci`、`npm run build`，需 Node `^20.19.0 || >=22.12.0`（当前 Vite 的要求）及 npm。已有完整 `web/dist/` 时运行不需要 Node。控制器只监听本机回环地址，复用已有 Python 环境和游戏启动脚本。

Rust对局服须预先构建：在项目根目录运行 `powershell -NoProfile -File scripts/Invoke-MatchCargo.ps1 build --release`。
随后随Python服务启动，无需另开终端。对局服直接监听UDP28970，构建/性能与验收见
[Rust对局服迁移](wiki/12-rust-match-server.md)。

完整启动时，入口等待三个游戏服务端口和控制器端口就绪，并检查控制器状态 API 与首页；`-NoGame` 只检查控制器就绪。重复运行会复用本项目的进程、恢复缺失或过期 PID 记录，不重启当前游戏。游戏启动失败或取消 UAC 后会尝试清理模拟服务器，Web 控制器保留；错误会显示 `runtime/logs/` 路径；重点检查 `server.stderr.log`、`controller.stderr.log` 和 `game-session-<PID>.stderr.log`。该就绪检查不代表游戏已进入大厅或关卡可玩。

如需只启动控制器，原入口 `scripts/Start-Controller.ps1` 仍可使用，并支持 `-PythonPath`。

- **游戏控制**：启动前先确认模拟服务器的四个端口就绪；停止时先确认游戏退出，再停止服务器及其Rust子进程。正常退出、手动关窗也由独立隐藏进程等待游戏退出事件并清理服务器，不依赖网页或轮询。游戏仍在运行时停服步骤不会执行；启动失败或取消 UAC 会尝试清理服务器，清理失败保留错误供重试。“停止游戏”也可清理游戏已经退出但仍残留的服务器。引导默认跳过，设置保存在 `runtime/data/controller.json`。
- **模拟服务器**：只读显示本项目 PID、认证/大厅/STUN/对局监听状态，不提供独立启停按钮。状态仅供调试，端口监听不等于对局可玩。
- **自动刷新**：当前页面可见时，每次状态请求完成后等待 10 秒再刷新，不并发堆积请求；隐藏页面暂停，返回立即刷新。游戏启停期间暂停轮询，操作成功或失败后立即重读游戏和服务器状态再恢复按钮。读取失败清除旧状态并禁用依赖游戏状态的操作，后续刷新成功后自动恢复。手动刷新仍保留。
- **中英切换**：顶栏 `English` / `中文` 切换整个控制台和 Wiki 阅读界面的语言，默认中文；选择保存于浏览器 `localStorage` 的 `codol-language`，刷新后保留。切换不清空输入、不改变请求参数和禁用规则。文档正文、文件名、账号与原始诊断详情保留原文。
- **开发 WIKI**：左侧按 `docs/` 的实际目录列出文件，右侧显示 Markdown 或 JSON。目录外源码及证据显示相对路径，避免误跳转为同名文档。
- **等级与货币**：退出游戏后可设置此版本最高的 3 转生 70 级、同步商城等级解锁值、分别增加游戏币和点券。游戏币购买、重登保持及点券购买已实测。
- **全部物品**：在“快捷操作”中点击“一键发放全部物品”，发放完整目录的 6772 种物品，期限设为永久，201 把武器写入对应满级经验；已有数量不叠加，余额不变。游戏内装备验收状态见 [物品与武器成长](wiki/09-inventory-completion.md)。
- **限时物品续期**：控制台已移除续期卡片；现有 `/api/inventory` 和 `/api/profile/renew` 接口保留兼容。所有数据操作写前备份，游戏运行时拒绝修改，重启游戏后读取。

## 页面设计依据

这是高频本地操作控制台，采用用户选定的方案 1「横向指挥台」：顶栏集中导航、刷新、主题与语言切换，下面依次为标题和启动/停止按钮、档案状态条；游戏币/点券独立卡片与服务器状态并排，下方快捷操作集中等级、剧情和全部物品三行，启动选项收为紧凑一行。Wiki 保留目录树与正文双栏。沿用 Radix Themes 组件，以蓝黑为主、保留浅色主题；游戏运行中展示档案修改锁定说明。

设计参数：`DESIGN_VARIANCE=4`、`MOTION_INTENSITY=3`、`VISUAL_DENSITY=8`。CODOL 使用紧凑斜体字标及双斜线标记，标题留白和余额卡片角落使用本地 SVG 等高线图案。卡片采用细描边、顶部高光和轻阴影，按钮与输入框保持统一尺度。仅提供一次入场、悬停抬升、按钮微光和按压反馈，不使用循环动画或新增动效依赖。

系统字体支持中文，余额使用等宽数字，交互保留键盘焦点；窄屏切换为纵向内容。SVG 通过 CSS 伪元素装饰，不拦截点击或进入无障碍名称。禁用按钮不触发悬停动效；`prefers-reduced-motion` 关闭动画、过渡与交互位移。

## 代码与状态归属

| 目录 / 文件 | 责任 |
|---|---|
| `web/src/` | React 页面、主题、Wiki 阅读 |
| `src/controller.py` | 本机 HTTP API、设置、游戏启动入口、受限 docs 读取 |
| `Start.ps1`、`tools/check-startup.py` | 环境检查、端口归属及就绪检查、一键启动 |
| `scripts/Start-Controller.ps1` | 隐藏运行控制器并记录 PID、日志 |
| `runtime/data/` | 玩家数据与控制器设置 |
| `runtime/backups/` | 修改前备份 |
| `research/evidence/` | REA 证据和有边界的运行时提取 |

接口不允许 docs 路径越界；写入接受同源 JSON，设置对布尔值严格校验。游戏启动复用现有管理员启动流程，UAC 由用户确认。

`POST /api/game/launch` 和 `/api/game/stop` 只接受 `{}`，与数据修改共用互斥锁，执行 `scripts/Control-Game.ps1`。启动保留现有 UAC、完整游戏路径和已验证的引导参数；停止复用 `Stop-Game.ps1` 的按路径核验。操作完成后复查游戏运行状态，失败不会报告成功。

`Control-Game.ps1` 把服务器启动、游戏启动和退出清理串在同一会话内。后台等待进程在游戏结束后清理服务器，项目级命名互斥锁防止上一局的退出清理误停刚启动的新一局。服务器启停仍由 `Control-Services.ps1` 核验进程与端口；命令行底层服务脚本保留供开发调试。新生命周期适用于经网页、根目录入口或 `Launch-Game.ps1` 启动的游戏；更新前已启动的游戏需下一次启动后采用该退出等待机制。关闭网页或网页控制器不结束当前游戏，后台等待进程仍负责游戏退出后的停服。

`GET /api/server/status` 返回 `running`、`pid`、`ready` 和四个 `ports` 的 `listening` / `conflict`：认证 TCP 443、大厅 TCP 3074、STUN UDP 3074、对局 UDP 28970。前三个端口必须属于本项目Python服务；对局端口必须属于指定路径、且父PID为该Python服务的Rust子进程。`ready`仅指这四个监听归属正确，不等于实机验收通过。Python按进程名称和完整脚本路径识别，兼容venv父子进程，不信任过期PID文件。独立 `/api/server/start`、`/api/server/stop` 写接口已移除，返回404。
