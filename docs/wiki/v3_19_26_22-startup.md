历史移植源码保留来源说明。新增C/C++源码通过公开x86 MinGW构建`version.dll`、`client_loopback319.dll`、`collision319.exe`和`ifs-read.exe`；旧加载器由Python替代，快照和NCS由版本内Python算法生成。游戏EXE、加密归档、转储、生成二进制及玩家数据不提交Git。

首次部署按[开发环境](../../CONTRIBUTING.md)安装Python依赖并构建网页，然后在仓库根指定32位编译器：

```powershell
$env:CODOL319_CC = 'C:\mingw32\bin\gcc.exe'
.\Start.ps1 -NoGame
```

在网页选择包含匹配EXE的原游戏目录并点击启动，确认Windows UAC。首次创建副本需要额外约24GB；代理使用ANSI路径，工具及运行目录须为较短的英文路径，所选原游戏目录可以包含中文。再次启动复用有效构建及资源缓存，不需要重新安装编译器。旧包可留作个人历史证据，程序不读取它。

也可只执行准备，不启动游戏或服务：

```powershell
python -B -m games.codol.versions.v3_19_26_22.client.preparation --source 'D:\原游戏目录' --runtime 'D:\CODOL-Revival\runtime\prepare319'
```

副本内安装源码构建的`version.dll`、系统32位version代理、生成的语言资源和`codol319-root.txt`；复制时排除Cross。原游戏保持只读，副本的原语言资源保留`.original`备份。首次出现“Optimize Settings?”时由用户确认；游戏进程创建后即返回启动结果，后台继续等待资源与大厅，不因用户停留此提示而关闭游戏。

发布配置由仓库明文生成；赛单从原游戏签名FF提取，只保留现有离线规则变换。英文翻译文本和共享字符串重定位规则见[资源来源](../../games/codol/versions/v3_19_26_22/resources/english/README.md)，字体、贴图等未改资产全部来自原游戏。`IFS2.dll`也来自已校验的原游戏，并非另找第三方启动组件。

启动后，监督进程校验自有游戏PID、创建时间、EXE路径及哈希，以只读权限导出物品、SKU、武器和配装表；所有文件发布完成后才写`common-ready.json`。库存/购买请求在此之前等待，认证和发布文件请求继续处理。对局按本次`gamestateupdate 6`提取当前地图碰撞和梯子，再发送首帧；不读取作者的固定PID地图转储。缺件、错误地图、资源校验或提取失败均阻断对应步骤并记录原因。

## 启停与验收边界

- TCP31900：本地认证；TCP31901：加密大厅；TCP8319：资源HTTP；UDP28970：按Ready事件启动的对局。均绑定回环地址。
- 各服务启动前检查端口，有冲突时不停止占用者；部分启动失败则清理本次创建的服务。对局仅在本次游戏的Ready事件后启动，端口冲突或原生组件指纹不符时显示错误，不反复重试。
- 管理员监督进程持有加载器和服务，停止请求只结束所持进程及加载器子树。状态同时记录PID与进程创建时间，旧PID文件不算运行证明。
- 普通控制器与管理员游戏使用同一实例。实例目录显式授权当前用户继承访问权；既有管理员日志按文件权限处理，避免继承标志在文件上无效。
- `ready`表示三个自有服务端点就绪；`game_running`表示目标游戏进程存活；本轮`secure_profile_read`和通用资源导出均完成后才标记`lobby_ready`。游戏菜单、移动和射击由用户验收。
- 服务档案在实例的`server/profile319.json`、`server/local-profiles319/`；新实例沿用源码默认值，不导入作者档案。重复准备和资源重建保留本实例进度。

## 启动设置与测试对局

网页档案操作及当前版本逆向证据见[3.19网页档案操作](v3_19_26_22-console.md)。

游戏停止时可在网页保存昵称、FOV和最高帧率。昵称接受3–15位英文字母、数字、下划线、连字符或方括号，以实际服务端限制为准；FOV为60–120，最高帧率为0–400，0表示不限制。设置按安装实例保存，下次启动生效；修改昵称会先备份原档案，并保留等级、经验和其他字段。游戏运行期间前后端均拒绝修改。

启动选项已前移至游戏目录下方。显示模式提供全屏、窗口化；分辨率提供1280×720、1366×768、1600×900、1920×1080、2560×1440、3840×2160。旧配置读取时沿用原有窗口化1280×720，保留昵称、FOV和帧率。启动通过 `CODOL319_EXTRA_ARGS` 传入 `r_fullscreen`、`r_mode`、`r_customWidth`、`r_customHeight`，移除加载器固定720p的 `--windowed` 参数；保留既有 `3291=0` 参数。

游戏语言支持简体中文和英文，旧配置默认沿用英文。简体中文从所选原游戏恢复`localization.txt`和`IIPS/IIPSDownload/ff_init_common_gfx_V109.ifs`至实例副本，并关闭加载器的`--english-resources`；英文从原游戏和仓库文本/变换规则重建这两份资源，并开启该参数。切换保留`.original`备份及玩家进度，不改原游戏；生成失败时先报错，不改现有语言资源。网页语言切换不修改游戏语言。

新增定向测试覆盖设置前移、表单保存与草稿保留、实例切换、旧配置兼容、输入拒绝、运行中禁改、语言资源往返及实际加载器进程创建参数。分辨率是否受当前显示器支持、全屏和窗口内的实际画面、游戏内中文显示仍需实机验收；此处不声明无边框全屏支持。
