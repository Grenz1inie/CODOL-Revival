# 两版本首次部署以可重建输入为边界

2026-10-17用户确认：3.3首次启动可备份并配置原游戏的`dwauth.ini`、`stun.ini`、`cacert.pem`，保留原CA且仅追加本实例CA；3.19继续用隔离副本，同时必须由仓库源码、原游戏及公开工具链完整重建，不依赖用户另找启动包，也不以随工具携带现成第三方原生二进制替代此目标。

此选择扩大了此前3.19“复用提供包”的交付边界：需要恢复或替代6个缺源码原生组件的必要行为，并补齐旧转储、快照和资源补丁的生成来源；代价是独立的逆向与验证阶段，收益是新环境不再依赖作者本机资产。现有玩家数据、EXE及系统设置的保护边界保持，方案与阶段验收见[首次部署方案](../plans/20261017-fresh-install-readiness.md)；本决定不表示实现或实机验收已经完成。
